# Empneon Core

Empneon Core is the game-agnostic cognitive runtime for persistent, state-aware game characters.
It provides structured identity, memory, grounded actions, bounded cognition, provider routing,
resource admission, telemetry, and replay.

For the complete project overview, architecture, development instructions, and documentation, see
the [Empneon README](https://github.com/mf-rl/Empneon#readme).

## Installation

Empneon Core is currently a beta release, available from PyPI and project releases.

```bash
python -m pip install empneon
```

Or install a wheel downloaded from a release:

```bash
python -m pip install ./empneon-X.Y.Z-py3-none-any.whl
```
