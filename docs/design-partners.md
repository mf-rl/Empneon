## Initial message

Hello [name/team],

I am building Empneon, an Apache-licensed, game- and AI-provider-agnostic runtime for
persistent NPC identity, social memory, bounded AI reasoning, validated game actions, and
developer replay/telemetry.

[One sentence specific to the studio and its game.]

Would you be open to a 30-minute technical discovery call? I am looking for three design
partners to pressure-test Empneon's adapter and runtime contracts against real simulation-game
requirements. The first call is exploratory: it requires no purchase, endorsement, public
attribution, source access, or integration commitment. If there is a fit, we would jointly
define one bounded evaluation scenario and decide whether to continue.

I can privately demonstrate the working Sims 4 reference experience, Godot portability proof,
resource-budget scheduler, persistent social memory, and replay/telemetry tooling.

Would [two concrete time options with time zone] work?

Regards,
[sender name and role]

## Discovery agenda

1. Current NPC scale, player-visible behaviors, and failure modes.
2. Engine, deployment, latency, hardware, and inference-cost constraints.
3. One scenario where identity, memory, beliefs, or social consequences matter.
4. Required authorial controls, debugging evidence, privacy, and safety boundaries.
5. Decide whether a bounded evaluation is useful; define success evidence if it is.
